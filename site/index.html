Network Test Tool

Network diagnostics for Windows, Linux and macOS. Run it without installing.

Windows (PowerShell)

irm https://droltr.github.io/Network_Test_Tool/run.ps1 | iex

Linux x86_64 / macOS Apple silicon

curl -fsSL https://droltr.github.io/Network_Test_Tool/run.sh | sh

What the command does

  • Downloads the latest release from GitHub into a per-user cache (%LOCALAPPDATA%\NetworkTestTool\bin or ~/.cache/network-test-tool/bin).
  • Checks its SHA-256 against the release's SHA256SUMS.txt and refuses to run on a mismatch.
  • Starts the app. No administrator rights, no installer, no registry or PATH changes.

Read the scripts before running them: run.ps1 · run.sh.

Manual download

If the command is blocked (for example by company security policy), download the file yourself from GitHub Releases.
